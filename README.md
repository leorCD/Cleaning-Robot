## 🤖 About
Each level is a mock house built to test what the robot can do, and your battery is always on the line. When you finish, the results appear on a clipboard checklist ("can clean windows," "can navigate to charging station"). Fail a task and it gets crossed out and stamped **REJECTED** or **SENT BACK FOR CALIBRATION**.

Every bot gets a random three-letter ID (AAA to ZZZ) and its own color. If you restart, you're following a different bot that made it to the same point.
